# Запуск проверки лабораторных

Команды выполняются из корня этого проекта. Нужны Python 3.10+, Git и настроенный Codex CLI с выполненным входом.

## Обычная проверка

```bash
./run_check.sh
```

Скрипт обновляет репозитории, проверяет работы и формирует JSON, индивидуальные Markdown-отчёты и сводную таблицу. Неизменившиеся работы и итоговые пятёрки пропускаются. Технические ошибки проверяются повторно.

## Перепроверка после изменения промпта

Промпт находится в `scripts/review_prompt.txt`. Для перепроверки всех работ, включая пятёрки и неизменившиеся файлы:

```bash
./run_check.sh --force
```

Начиная со второго задания включительно, для всех групп:

```bash
./run_check.sh --force --start-lab lab02
```

`--start-lab` принимает ID из `labs.json`. Для каждой группы проверяются выбранная лабораторная и все последующие; результаты предыдущих лабораторных сохраняются. Синхронизация репозиториев в `run_check.sh` всё равно выполняется для всех групп.

Чтобы сохранить дату проверки, дату сдачи и штраф задания 1, укажите `--start-lab lab02`, в том числе при использовании `--force`. Сам по себе `--force` разрешает перепроверку всех выбранных заданий. Параметр `--start-lab` без ID — ошибка запуска.

Задание 6 не отправляется на AI-проверку, если в зафиксированной версии репозитория нет файлов в `solution/` или `report/`; один `README.md` или `.gitkeep` не считается результатом. В отчёте указывается «Не сдано» и отсутствующая папка.

## Если Codex CLI отсутствует в PATH

Укажите путь к исполняемому файлу:

```bash
CODEX_BIN=/полный/путь/к/codex ./run_check.sh --force --start-lab lab02
```

Например, в текущем окружении:

```bash
CODEX_BIN="$HOME/.codex/packages/app-server-daemon/releases/0.166.0-x86_64-apple-darwin/bin/codex" ./run_check.sh --force --start-lab lab02
```

Путь с номером версии может измениться после обновления приложения.

## Отдельные этапы

Обновить репозитории:

```bash
python3 -B scripts/sync_repos.py
```

Запустить только перепроверку, без скачивания репозиториев и построения Markdown:

```bash
python3 -B scripts/check_labs.py --force --start-lab lab02
```

Для этой команды путь к CLI можно передать через `CODEX_BIN` или `--codex-bin /полный/путь/к/codex`. Дополнительные параметры: `--model ИМЯ` и `--timeout 600` (секунды на одну работу).

Пересобрать сводную таблицу и индивидуальные отчёты из имеющихся JSON:

```bash
python3 -B scripts/render_summary.py
```

## Результаты

- `results.md` — сводная таблица.
- `results/<group_id>/<lab_id>.md` — отчёт для студентов.
- `results/<group_id>/<lab_id>.json` — результат проверки работы.
- `aggregated.json` — результаты всех групп.

Группы без ссылки получают статус `no_repository`, отсутствующие работы — `not_submitted`. Статус `error` означает технический сбой, причину смотрите в поле `technical_error` соответствующего JSON. После устранения причины повторите запуск.

Проверьте отчёты перед публикацией. Commit и push выполняются вручную.
