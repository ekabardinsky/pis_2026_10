## Резюме

ER-модель охватывает заявки на дактилоскопию, документы, проверки, запись и результат, но в данных заявки не хватает полей для проверки применимости услуги и расчёта срока по дорожной карте.

## Обязательно исправить

- В `student/er.md`, сущность `APPLICATION` не хранит планируемую длительность пребывания и дату подачи на патент. По пунктам 2.1–2.2 дорожной карты эти данные нужны, чтобы определить применимость дактилоскопии и рассчитать срок: для нетрудовой цели — проверить пребывание свыше 90 дней, для работы — учесть более раннюю дату подачи на патент. Добавьте необходимые поля, иначе правила из пояснений нельзя проверить по данным модели.

## Желательные улучшения

- В `student/er.md`, пример прохождения содержит опечатку «значить срок соблюдён»; замените на «значит, срок соблюдён».
- Содержание видео не проверяется; наличие видеофайла в `report/` по переданному контексту не подтверждено.
